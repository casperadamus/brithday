# brithday 🌷

A little birthday website for Mom.

## Adding your photos

1. Put your photos in the `photos/` folder (e.g. `photos/1.jpg`, `photos/2.jpg`, …).
2. Open `content.js` and make sure the `photos` list matches your file names. Add or remove entries as you like, and change the captions.

Any photo that isn't there yet shows a soft "photo coming soon" placeholder, so the page never looks broken.

## Changing the words

Everything you can read on the page (her name, your name, the letter, the "things I love about you" list, the surprise message) is in `content.js`.

## Seeing it

Just open `index.html` in a browser. To share it with a link, turn on GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → `main` / root**. Your site will be at
`https://<your-username>.github.io/brithday/`.
